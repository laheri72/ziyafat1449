## 2024-05-24 - Missing ARIA Labels on Icon Buttons\n**Learning:** The application uses FontAwesome icons heavily as standalone buttons (like view, edit, delete, download). Without ARIA labels or screen-reader only text, these buttons provide zero context to visually impaired users, violating basic accessibility standards.\n**Action:** Add `aria-label` attributes to all icon-only buttons to convey their action (e.g., 'View User Details', 'Delete User'). I should proactively look for and address this pattern across all management pages (users, books, duas).
