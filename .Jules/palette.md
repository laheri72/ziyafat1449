## 2024-05-18 - Topbar Accessibility Enhancement
**Learning:** Found multiple instances where interactive UI elements in `includes/header.php` relied purely on visual cues or placeholders for context. The sidebar toggle button was icon-only (`fas fa-bars`), and the global search input used a `placeholder="Search..."` attribute without an explicit label or `aria-label`. This makes these controls difficult to understand or inaccessible to screen reader users.
**Action:** Consistently added `aria-label` and `title` to icon-only buttons (`menuToggle`). Added `aria-label` to input fields that only use visual placeholders (`topbar-search`), and marked decorative font-awesome icons with `aria-hidden="true"` to prevent redundant screen reader announcements. I will continue checking for similar patterns on interactive topbar and navigation elements.
